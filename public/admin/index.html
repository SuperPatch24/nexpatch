Before you turn these on

Session length and idle timeout need the auth_time claim in the API's access tokens. In Microsoft Entra, open the NexpatchOnline app registration → Token configuration → Add optional claim → Access → auth_time. Without it the limits can’t be enforced, and the dashboard shows a warning.

Require MFA works through a Conditional Access authentication context, because Microsoft’s v2 access tokens don’t say whether MFA was used. In each organization that must use MFA, an administrator creates the authentication context (for example c1) in Entra → Protection → Conditional Access → Authentication contexts, and a Conditional Access policy that requires MFA for that context. People in an organization that hasn’t done this can’t sign in while MFA is required, so turn it on per organization once they are ready. The dashboard’s “MFA sign-ins” column shows who is already set up.

WinGet discovery

Every three hours the platform reads the apps that trusted vendors publish on WinGet and checks each one. Ready: HTTPS download with a SHA-256 hash from the vendor’s own website, a whole-device installer that installs silently, and a named publisher and licence. Needs review: deployable, but one check needs a person, usually a download from another host. Skipped: Intune can’t deploy it as it is (portable or per-user only). Nothing is added until you add it, and every app is verified again when you do.
