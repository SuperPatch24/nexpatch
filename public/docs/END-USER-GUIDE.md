# NexpatchOnline — End User Guide

> This guide is for employees using NexpatchOnline to check application status and request software. Your organization’s IT administrator controls which actions are available.

## 1. Sign in safely

1. Open the NexpatchOnline URL supplied by your IT team.
2. Select **Sign in with Microsoft**.
3. Use your organization work account. Personal Microsoft accounts may not be accepted.
4. Complete your organization’s multi-factor authentication prompt.
5. If you see an access denied message, contact your IT administrator and provide the exact sign-in email shown by Microsoft. Do not send passwords or authentication codes to support.

## 2. Find an application

1. Open **App Catalog**.
2. Search by application name or publisher.
3. Open the app details and read the description, publisher, version and availability notes.
4. If the application is missing, choose **Request an application** rather than downloading an installer from an unknown website.

Only applications approved for your organization should be installed. Catalog visibility does not mean every app is available to every user or device.

## 3. Request software

Include as much information as possible:

- Exact application name and publisher.
- Vendor's official website.
- Business reason and team that needs it.
- Required version, architecture and language.
- Whether the application is free, licensed or subscription-based.
- Any special installation requirements.

If your organization permits file uploads, upload only an installer obtained from the vendor's official source. Do not upload confidential data, license keys or personal information. Uploaded files are for administrator review and are not automatically executed.

## 4. Track a request

Open **My Requests** to review the current status and any administrator comments. Typical stages include Submitted, Under Review, More Information Needed, Packaging, Testing, Approved, Published and Declined. Availability depends on the workflow enabled by your IT team.

## 5. Updates and notifications

Your IT team may deploy approved updates automatically according to maintenance windows and deployment rings. Save your work before a scheduled restart. If an update fails, record the device name, application, time and any displayed error, then contact IT.

## 6. Privacy and acceptable use

Use the service only for your organization’s approved business purposes. Do not attempt to bypass device controls, alter deployment scripts, upload malware, or use another person's account. Activity may be logged for security, troubleshooting and audit purposes under your organization's policies.

## 7. Troubleshooting

| Problem | What to do |
|---|---|
| Sign-in denied | Confirm the work account and ask IT to check access assignment and invitation email. |
| App not listed | Submit an application request with vendor details. |
| Request stuck | Check request comments and contact your IT help desk with the request ID. |
| Install failed | Restart only if instructed; provide the device and app details to IT. |
| Unexpected prompt | Stop and contact IT. Never approve an unfamiliar consent request. |

## 8. Getting help

Contact your organization's IT administrator or the support address published by your organization. Include the request ID and relevant error text, but never include passwords, tokens, private keys or recovery codes.
