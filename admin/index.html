Organizations

Every connected customer organization. Revoke access when a subscription is done, suspend an organization to make it read-only, and set per-organization limits, features and invitation rules.

OrganizationSubscriptionUsageAccess
Open this tab to load organizations.

Revoking blocks every sign-in for that organization within about 30 seconds and stops its nightly syncs. Nothing is deleted, so restoring access brings everything back. It does not remove NexpatchOnline from the customer’s Entra ID; ask them to remove the enterprise application if they are leaving for good.
