Shared catalog

Changes here are visible in the same client App Catalog. Use Find and add to look an app up by name: it is verified before it can be added. You can also add, edit or remove entries by hand.

Find and add an app

Type an app name. NexpatchOnline searches WinGet and the Microsoft Store, checks that each match exists and can be installed, and only verified matches can be added.

Browse a vendor

See everything a vendor publishes on WinGet, for example Microsoft or Oracle, and add the apps you want. Each app is verified when you add it. Check a vendor’s license terms before offering an app to customers (for example Oracle Java).

New versions detected

The platform checks each app’s vendor source about once a day. Detection only records the new version: nothing is packaged or published automatically, and customers with auto-publish turned on receive it at their next publish run.
